Privacy

  • Nothing is read or sent before you press Send.
  • Only the trimmed, redacted incoming message and draft leave this device, once per send attempt. Emails, links, phone numbers and long ID numbers are replaced before that.
  • The relay keeps nothing and returns numbers only.
  • The extension holds no API key and no account.
